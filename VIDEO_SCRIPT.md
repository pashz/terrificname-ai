# TerrificName AI — Submission Video Script (60-90 seconds)

## Format
- **Length**: 60-75 seconds (under 60 is better for social loops)
- **Resolution**: 1080p vertical (9:16) for TikTok/Reels + 1080p horizontal (16:9) for YouTube
- **Captions**: Auto-captions via CapCut (white text, black outline, centered)
- **Music**: ElevenLabs Music generated soundtrack or subtle lo-fi from CapCut library
- **Hook audio**: Use ElevenLabs TTS voice for the opening line — shows the tech immediately
